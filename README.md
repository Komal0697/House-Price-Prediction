# House-Price-Prediction
Machine Learning project for predicting house prices using Python.

# Project Overview: 
  This project focuses on predicting house prices using machine learning techniques.
  The dataset contains various features related to houses, which are analyzed and used to build a prediction model.

# Problem Statement:
  To develop a Machine Learning model that cal predict the sales price of a house based on its features.

# Technologies Used:
1. Python
2. Pandas
3. Numpy
4. Matplotlib
5. Seaborn
6. Scikit-learn
7. Jupyter Notebook

# Project Steps:
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Preprocessing
5. Feature Selection
6. Train Test Split
7. Model Building
8. Model Evaluation
9. House Price Prediction

# Machine Learning Model:
Random Forest Regression
AdaBoost Regression
Gradient Boosting Regression

# Evaluation Metrics:
1. MAE
2. MSE
3. RMSE
4. R2 Score

# Conclusion:
  The project demonstrates the complete Machine Learning workflow,starting from data preprocessing and exploratory analysis to model building and house price prediction.
